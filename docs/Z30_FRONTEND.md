# Z30 前端与升级说明

## 版本基线

本次基于 [Wei-Shaw/sub2api v0.2.20](https://github.com/Wei-Shaw/sub2api/releases/tag/v0.2.20) 做了真正的 Git 合并，而不是只改版本字符串。合并的两个父提交为二开版本 `fe25ea33d` 和官方发布提交 `dab829a4e`。官方的模型及 OAuth 更新与二开的模型条目、验证码和网关逻辑共存；新版本的邮箱注册黑名单设置与本地 Grok 计费设置都保留了。

## 图形与界面

- **标准标**：`frontend/public/z30-emblem.svg`。Z、3、0 是独立绘制的玻璃字形。画板 224 × 92，没有色底、外圈或底板。SVG 内部以低透明度字面和前后切边表现玻璃厚度，字间与 0 的内孔完全透明。
- **小标**：`frontend/public/logo.svg`。简化装饰和渐变，供 favicon 和界面默认品牌图使用。运营方配置的站点名称和 logo 仍优先用于站点导航。
- **单色标**：`frontend/public/z30-mono.svg`。与主标共用字形，作为 3D 网格的轮廓源，也适合单色印刷；内联 SVG 时可通过 CSS `color` 上色。
- 首页只有默认模式显示全屏 Z30 场景。后台已配置的自定义首页（HTML 或 URL）和精简首页继续走自己的分支；模型广场、登录和控制台入口仍受原有配置与登录状态控制。
- 控制台沿用 Vue 3、Tailwind 3 与原有路由。以 [shadcn/ui](https://github.com/shadcn-ui/ui) 的 [Vue 移植版](https://www.shadcn-vue.com/) 为组件来源，直接维护注册表源码。组件目录为 `frontend/src/components/ui`，语义颜色与圆角为 `frontend/src/styles/tokens.css`。新组件使用 `bg-background`、`text-foreground`、`border-border` 等语义类，不单独假设浅色或深色背景。
- 首页场景借鉴 [Active Theory](https://activetheory.net/) 的留白和中央构图。首页按需加载 Three.js，用同一 SVG 字形生成有厚度、倒角和真实内孔的网格。WebGL2 在同一个透视场景内多次绘制：先生成当前相机可见的透射背景，再读取玻璃背面信息、计算按波长分开的出射光线。默认首页是一条完整的原生滚动镜头路线，没有吸附滚轮或拖动页面的脚本。镜头离开 Z30，穿过粒子河和宣言文字，绕过模型图谱的展面，沿数据管线进入 API 控制台，最后停在服务状态观测站。反向滚动沿原路返回；页底不会跳出另一套卡片。登录入口和章节跳转始终可用。
- 章节锚点：`/home#origin`、`/home#plaza`、`/home#connect`、`/home#observatory`。滚动控制器基于实际滚动距离与视口高度计算进度，不依赖滚轮输入；触屏、键盘与浏览器返回按钮同样可用。减少动态效果时显示各章关键视角。WebGL 不可用时保留透明 SVG、章内文字、艺术展面和业务入口。
- 服务状态沿用真实公共接口；未开启公开监控、未配置记录和查询失败分别显示。复制 API 地址支持后台配置的自定义端点。主标、粒子场与模型展面是仓库自有资产，页面不加载参考站的脚本或素材。

## 从开场到观测站

- 原生页面滚动给出镜头的目标位置。玻璃、镜头、展面和字幕共用一个临界阻尼进度，不各自追滚轮；停止时自然收稳，反向滚动沿原路回访。暂停、减少动态效果和章节锚点直接定位。
- 实时模式只有一个可见 WebGL 画布、一台透视相机。Z30 是有厚度和真实内孔的字模，左右晶体是封闭的弯曲实体。远处的发光细线、微粒和材料面先在同一相机下绘制；字模的背面法线、出射位置和折射率决定最后采样哪一个背景像素。鼠标改变观察位置，字面与 0 的空洞因而呈现不同的光路。
- 相机初始 z=18，字模中心 z=7.1；向前滚动到约 15% 时，相机从字模左侧越过这个深度，再进入粒子河。字模不跟着相机缩放、侧转或淡出；第一、二幕之间没有幕布截帧、二维放大或图片遮罩。正反向滚动使用同一条世界坐标样条。浏览器原生滚动、键盘、登录与章节链接照常可用。
- 常规尺寸下主画布至少保持 CSS 像素密度。透射背景与可见绘制缓冲等大，每帧刷新；水面用单独的镜像相机。只有 WebGL 不可用、上下文丢失或系统强制色彩模式才进入静态后备路径，保留 SVG、各章节及操作。在支持图形渲染的设备上开启减少动态效果，会固定章节机位，而不是不断播放。
- 验证流畅度时区分浏览器动画回调、实际 WebGL 提交和屏幕呈现。相同显卡、视口和滚动脚本下的提交间隔可作前后对照，但不是其他设备的帧率承诺。

## 首页美术：光学陈列室

- 宽屏与竖屏按实际画幅配置三维晶体构图；摄影风格的双画幅开场图现在仅用于无 WebGL 的静态后备。正常开场不加载这两幅图或旧版高光蒙版。
- 首屏说明产品用途。运营方自定义的站点名称、徽标和副标题仍有优先权；登录与章节导航保持可见。没有公开监测时展示真实的关闭状态。
- 模型目录采用四件原创材料习作：铜质叶片、青色萤石、叠层光学镜片、悬浮金色弧面。模型名称跟随各自的展面。第三幕的实际分光组件通过光学导轨把运动带到第四幕的机械光阑；光阑、支架和底座共同参与水面倒影。
- 运行时读取 `frontend/public/assets/home/atelier-*.webp`，不依赖外部图片服务。原始美术是为本项目生成的图像，不是参考网站截图。重新打包时运行 `python frontend/tools/package-atelier-plates.py --landscape <横幅.png> --portrait <竖幅.png> --folio <四联画.png>`，得到两种画幅、局部高光蒙版及四件作品。

## 在本地复验

在 `frontend` 目录执行 `pnpm install --frozen-lockfile`、`pnpm build`；生产构建输出到后端嵌入目录。通过 `pnpm test:run` 检查前端回归。启动项目后分别访问 `/home`、`/login`、`/key-usage` 和启用后的 `/model-plaza`，检查窄屏导航、键盘焦点、减少动态效果偏好与中英文切换。确认“自定义首页”和“精简首页”均关闭后，再验收 Z30 默认场景。

本次变更作用于本地源码，没有部署到线上。发布前请备份数据库，并用当前生产配置在预发布环境演练新增迁移；源码回滚不等于数据库回滚。
